# CAR-DATA-PRICE-AND-SALES-PREDICTION
Built a machine learning model to predict car prices and company sales performance using historical data. The dataset included features such as car brand, model year, engine size, mileage, fuel type, transmission, and sales figures.

Performed data cleaning, feature engineering, and exploratory data analysis to uncover key insights — such as the impact of brand reputation, mileage, and fuel efficiency on pricing and sales. 

Achieved high accuracy on test sets and visualized feature importance to understand key drivers behind pricing and market performance.

Key Tools: Python, Pandas, Scikit-learn, Matplotlib, Seaborn, 
Jupyter Notebook
